# Overview & Scope
**3 Key points for make this project success**

Main Board System
_เป้าหมาย: ดึงดูดความสนใจในระยะสั้นและกระตุ้นการเล่นซ้ำทุกวัน_
- กระดานขนาด 7*9 ที่ไหลลื่นและเข้าใจง่าย
- ความท้าทายเชิงกลยุทธ์และการจัดการทรัพยากร
City Building System
_เป้าหมาย: สร้างความผูกพันและความภาคภูมิใจให้ผู้เล่น_
- ระบบซ่อมแซมและตกแต่งเมืองที่เห็นความเปลี่ยนแปลงชัดเจน
- สมุดสะสมคอลเลกชันเพื่อเป้าหมายระยะยาว
Story System
_เป้ามาย: รักษาฐานผู้เล่นในระยะยาว (Long-term Retention)_
- การดำเนินเรื่อง 15 บทที่น่าติดตาม (Cliffhanger)
- ระบบความสัมพันธ์ตัวละครที่ส่งผลต่อการเล่น

Total effort 687 Man-Days
- Intfrastructure
- All main feautures
